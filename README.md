# হোম ক্যামেরা

WebRTC + PeerJS দিয়ে বানানো সিম্পল লাইভ ক্যামেরা অ্যাপ।

## ব্যবহার
1. ক্যামেরা ফোনে সাইট খুলে "ক্যামেরা" বেছে একটা গোপন কোড দাও।
2. ভিউয়ার ফোনে "ভিউয়ার" বেছে একই কোড দাও।
3. ক্যামেরা ফোন চার্জারে লাগিয়ে রাখো।
